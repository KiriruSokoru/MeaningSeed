# Эксперимент 02: Арифметика и усиление мастеров

## Статус
✅ **ЧАСТИЧНЫЙ УСПЕХ**

## Цель
Найти мастер-нейроны в Qwen Instruct на арифметике (5-значные числа) и перенести их в Qwen Base.

## Что делали
1. Сгенерировали 100 арифметических задач (5-значные числа, + и -)
2. Нашли мастеров в Instruct (60 нейронов в k_proj/q_proj)
3. Применили семя к Base с разными коэффициентами (1.3, 1.5, 2.0)
4. Контроль: случайные нейроны

## Результаты

| Коэффициент | Точность ДО | Точность ПОСЛЕ | Дельта | Статус |
|-------------|-------------|----------------|--------|--------|
| 1.3 | 6% | 11% | +5% | ✅ Улучшение |
| 1.5 | 6% | 0% | -6% | ❌ Сингулярность |
| 2.0 | 6% | 0% | -6% | ❌ Коллапс |
| случайные 1.5 | 6% | 46% | +40% | ⚠️ Аномалия |

## Сканирование коэффициентов (1.1–1.5)

| Коэф. | Мастеры | Случайные |
|-------|---------|-----------|
| 1.1 | 0% | 10% |
| 1.2 | 10% | 2% |
| 1.3 | 10% | 0% |
| 1.35 | 10% | 2% |
| 1.4 | 4% | 12% |
| 1.45 | 0% | 10% |
| 1.5 | 0% | 46% |

## Выводы
1. Мастера существуют, их лёгкое усиление (×1.3) даёт улучшение (+83% относительно базы)
2. Есть порог между 1.3 и 1.5, после которого мастера превращаются в сингулярности
3. Случайные нейроны могут случайно попасть в flow field (46% при ×1.5), но это нестабильно
4. Оптимальный коэффициент: **1.3**
