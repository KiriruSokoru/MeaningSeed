# Эксперимент 01: Перенос JSON-навыка

## Статус
❌ **НЕУДАЧА**

## Цель
Проверить, можно ли перенести мастер-нейроны из Qwen Instruct в Qwen Base на задаче генерации JSON.

## Что делали
1. Нашли мастера в Qwen Instruct по стабильности (высокая средняя + низкая дисперсия)
2. Сохранили семя (60 мастеров в k_proj/q_proj)
3. Применили семя к Qwen Base с усилением ×1.3, ×1.5
4. Проверили точность генерации JSON

## Результаты
- Базовая точность Qwen Base ДО: уже умеет JSON
- Усиление не дало значимого улучшения
- Эксперимент не показал разрыва между моделями

## Почему провал
Qwen Base оказался уже обучен на JSON. Модель генерирует валидный JSON до любой операции.

## Вывод
Для будущих экспериментов нужны задачи, где Base модель объективно хуже Instruct:
- Арифметика с 5+ цифрами
- Редкие сущности
- Вариативная структура
