# MeaningSeed

**Мгновенное переключение задач в LLM через топологические семена.**

> Забудьте о хранении десятков LoRA-адаптеров и часах дообучения.  
> MeaningSeed позволяет переключать контекст нейросети между задачами за миллисекунды, используя топологические "семена" размером всего в десятки килобайт.

## 🧠 Концепция

MeaningSeed применяет принципы дифференциальной геометрии (кривизна Оливье-Риччи) к пространствам активаций нейросетей. Мы обнаружили, что навык модели удерживается не всеми её весами, а небольшим подмножеством нейронов — **топологическими мастерами**.

Эти мастера выступают "семенами смысла" (Meaning Seeds):
- 📦 **Компактность**: ~50-100 КБ на задачу вместо сотен мегабайт
- ⚡ **Мгновенность**: переключение контекста за 1 эпоху прогрева
- 🎯 **Изоляция**: базовая модель не деградирует, нет catastrophic forgetting

## 🚀 Быстрый старт

### Установка


git clone https://github.com/KiriruSokoru/MeaningSeed.git
cd MeaningSeed
pip install -r requirements.txt

###Извлечение семени из задачи

Создайте файл math_task.jsonl с примерами:

{"text": "Q: 2 + 2 = ?\nA: 4"}
{"text": "Q: 15 * 3 = ?\nA: 45"}

Извлеките семя:

python cli.py extract \
    --model distilgpt2 \
    --dataset math_task.jsonl \
    --task math \
    --output seeds/math.pt \
    --masters-per-layer 10
    
Внедрение семени в модель

python cli.py inject \
    --model distilgpt2 \
    --seed seeds/math.pt \
    --warmup 1 \
    --test-prompt "Q: 25 + 17 = ?\nA:"

Python API

from meaning_seed import Orchestrator, SeedRegistry

# Загружаем семя
seed = SeedRegistry.load_seed('seeds/math.pt')

# Создаем оркестратор с базовой моделью
orch = Orchestrator('distilgpt2')

# Внедряем навык
orch.inject_seed(seed, warmup_epochs=1, dataloader=math_loader)

# Модель теперь эксперт в математике!
print(orch.generate("Q: 25 + 17 = ?\nA:"))

# Мгновенно очищаем модель
orch.eject_seed()

🔬 Как это работает

    Экстракция: Обучаем модель задаче и вычисляем кривизну Оливье-Риччи для графа корреляций активаций каждого слоя. Нейроны с высокой положительной кривизной — это "мастера".
    Архивация: Сохраняем веса только мастеров. Для distilgpt2 это ~50-100 КБ.
    Оркестрация (Inject): Внедряем веса мастеров в базовую модель и делаем 1 эпоху целевого прогрева (обновляются только мастера через маскирование градиентов).
    Очистка (Eject): Возвращаем базовые веса на место мастеров. Модель мгновенно "забывает" задачу.

🧬 Научная основа
Проект основан на Гипотезе Сокола и применении дифференциальной геометрии к нейросетям. Подробное математическое обоснование и история экспериментов: BrainTopologyLLM
.
Ключевые оптимизации:

    Degree Capping: ограничение степени узла при построении графа (ускоряет расчет Риччи на порядки)
    Targeted Warmup: маскирование градиентов для обновления только мастеров
    Распределенное извлечение: мастера извлекаются из всех слоев, а не только из последнего
